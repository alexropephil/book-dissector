# 拆书 · 四维拆解 + 读者视角 + 人读笔记

把一部小说按四个维度拆开，看清它到底为什么好看：结构怎么搭的、规则怎么立的、人怎么活的、文字什么风格。

外加一个读者视角，模拟真实读者读这本书的感受。技术拆解回答“为什么好”，读者体验回答“好在哪、有多好”。

最后笔记师把拆解结果写成一份人读笔记。输出六份结构化报告加一份人读笔记，给写作拆解、风格模仿、技法学习用。

## 四个维度 + 读者视角

| 维度 | 回答的问题 | 角色提示词 |
|------|-----------|-----------|
| 剧情 | 主线怎么搭？因果链自洽吗？节奏怎么控？ | `personas/plot.md` |
| 世界观 | 世界规则是什么？力量体系怎么运转？势力怎么分布？ | `personas/world.md` |
| 人物与情感 | 主角想要什么、怎么变？配角独立吗？关系网怎么织？ | `personas/character.md` |
| 文风 | 文字什么风格？对话分得出人吗？有没有 AI 味？ | `personas/style.md` |
| 读者视角 | 读者读到什么感受？哪里上头？哪里想弃书？ | `personas/reader.md` |

## 这套框架怎么来的

这六个 persona 不是泛泛的身份提示词，是从一套**写作诊断体系**里逆向提炼出来的完整工具。

写作时，你要检查爽点密度够不够、角色弧线卡没卡、文风有没有 AI 味；拆书时反过来，你问作者多久给一次爽点、弧线怎么走通的、天然的语言习惯是什么。同一个概念，正向是诊断自己，逆向是拆解别人。

关键是，这套 persona 带着**真实的判断标准**，不是空话：

- 剧情里写着“连续 3 章无钩子是失效线”“爽点间隔 3 到 5 章是标准”
- 人物里写着七种弧线故障的判定条件，以及“把开篇被欺负的场景放到现在，主角的选择还一样吗”这种可操作的检查
- 文风里写着 AI 味的十五种模式，和句长标准差这种量化指标

所以你用普通的“帮我分析这本书”问 AI，得到的是泛泛的通用分析；用这套 persona，得到的是有标尺、可复现、能落到原文的拆解。

## 快速开始

你只需要一个普通的 AI 助手（哪怕是全新的、什么都不懂的），加上这个项目的 persona 文件。

### 第 1 步：拿到 persona

克隆仓库，或直接下载 `personas/` 目录。里面六个文件：五个视角，加一个“笔记师”（把拆解结果写成人读的笔记）。

### 第 2 步：复制一个 persona

想拆哪个维度，就打开哪个文件，复制全文。比如想拆剧情，复制 `plot.md` 的全部内容。

### 第 3 步：粘给助手，用这段启动提示词

把下面这段整段复制给你的 AI 助手，把括号里的地方填上：

```text
你现在扮演一个拆书分析师。你的唯一依据是下面这段“角色提示词”，严格按它执行，不要加入角色提示词之外的任何经验、判断或风格。

=== 角色提示词 ===
（粘贴 personas/ 目录下某个 .md 文件的完整内容）
=== 角色提示词结束 ===

分析对象是《书名》第 X-Y 章，正文如下：

=== 正文 ===
（粘贴书的正文）
=== 正文结束 ===

请按照角色提示词里的拆解维度和输出要求，输出分析报告。正文很长的话，可以分段分析，最后合并成一份完整报告。
```

整段对话就三步：你粘贴、助手读取、助手按 persona 输出报告。不用额外解释，助手会自己照着角色提示词走。

### 拆全部五个维度

读者视角先行，四维随后，再做综合判断，最后笔记师把六份报告写成一份人读笔记。单个助手就依次喂 persona，多个助手就各开一个会话。完整流程见 `docs/workflow.md`。

## 两种报告，两种读者

这套框架跑出两类报告：

- **AI 阅读版**（01-06 六份）：结构化、清单化、数据化。给 AI 用——AI 提取技法、建素材库、生成可复用规则，靠这个。可复现、可靠。
- **真人阅读版**（07 拆书笔记）：有立场、有温度、有节奏。给人读——人读完要有启发，能带走一句话。

想给 AI 当素材，看 01-06；想自己学东西、偷手艺，读 07。

## 目录结构

```
book-dissector/
├── personas/      # 角色提示词（四维 + 读者视角 + 笔记师），可独立使用
├── templates/     # 输出模板（六份给 AI + 一份人读笔记）
├── examples/      # 拆书示例（含元信息）
├── docs/          # 拆书框架的方法论说明与执行流程
```

## 适用场景

- 拆解一本让你上头的书，搞清楚它好在哪
- 学习某个作者的节奏、人设、文风
- 给自己的稿子建立可对照的分析基准
