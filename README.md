# 拆书 · 四维分析系统

把一部小说按四个维度拆开，看清它到底为什么好看：结构怎么搭的、规则怎么立的、人怎么活的、文字什么风格。

输出四份结构化报告，给写作拆解、风格模仿、技法学习用。

## 四个维度

| 维度 | 回答的问题 | 角色提示词 |
|------|-----------|-----------|
| 剧情 | 主线怎么搭？因果链自洽吗？节奏怎么控？ | `personas/plot.md` |
| 世界观 | 世界规则是什么？力量体系怎么运转？势力怎么分布？ | `personas/world.md` |
| 人物与情感 | 主角想要什么、怎么变？配角独立吗？关系网怎么织？ | `personas/character.md` |
| 文风 | 文字什么风格？对话分得出人吗？有没有 AI 味？ | `personas/style.md` |

## 这套框架怎么来的

四个 persona 不是凭空写的身份提示词，而是从一套**写作诊断体系**里逆向提炼出来的。写作时你要检查爽点密度、角色弧线、文风有没有 AI 味；拆书时反过来，你问作者多久给一次爽点、弧线怎么走通的、天然的语言习惯是什么。同一个概念，正向是诊断自己，逆向是拆解别人。

## 快速开始

1. 准备目标书的 txt 文件
2. 打开 `personas/`，把四个角色提示词分别喂给四个 AI 会话（或依次喂给同一个 AI），各自附上书的正文和对应维度
3. 按 `templates/` 里的骨架收口，四份报告输出到同一个目录

## 目录结构

```
book-dissector/
├── personas/      # 四个维度的角色提示词，可独立使用
├── templates/     # 四份输出模板，照着填
├── examples/      # 用公版书跑出的完整示例
└── docs/          # 四维框架的方法论说明
```

## 适用场景

- 拆解一本让你上头的书，搞清楚它好在哪
- 学习某个作者的节奏、人设、文风
- 给自己的稿子建立可对照的分析基准
