# 拆书框架问题清单与改法方案

> 基于斗破苍穹前 20 章的对照实验（empty 空 agent vs 阿星）、阿星对报告的自我审视，以及阿星对初版方案的校准，梳理出的问题与改法。

> 状态：以下改法已于 2026-08-14 全部落实（persona 从裁判改提问者、加类型史位置、允许跨维度、综合判断、执行者授权、降级评级），并通过第二轮对照验证（empty + 阿星）。本文档保留作为问题诊断和改法决策的历史记录。

## 一、问题清单

按根因到表象排列，一共五个。

### 根问题：persona 是"裁判"，不是"提问者"

persona 预设了一套审美立场，并把这些立场伪装成客观标准。书不合立场时，它不说"标准不适用"，而是逼执行者把 genre feature 报成 flaw，写出自己都不信的结论。

这个"taste 伪装成中立"有两层：

- **审美标准层**："套路要超越""弧线要走完""世界观要能生长""写实约束要守"，表面是检查点，实际是立场
- **语气姿态层**：reader 那句"要温和、要让作者被理解、别当编辑"，同样是 taste 伪装成中立纪律，它压制的正是更狠的判断

### 衍生一：历史错位

用今天的"套路超越"框架，去量 2009 年发明套路的书，把"发明者"误判成"超越者"。persona 缺一个维度：这本书在类型史上的位置。

### 衍生二：跨维度洞察被"别带入"拆碎

"切换维度时不带入其他维度"这条纪律，让五份报告各自独立抱怨"设定灌输多"，却永远没法合成"设定灌输就是爽文的信息流风格"这个真正值钱的跨维度判断。

### 衍生三：输出目标错位

报告的目标被设成了"填满评级表、完成 checklist"，而不是"给写作者留一句能带走的话"。"节奏是工程不是灵感"这种真货被埋没，就是目标错位的症状。这不是"输出要求不够狠"——再往狠里写命令，只会让执行者更顺从地填格子。

### 衍生四：执行者缺授权 + 会圆场

执行者不是白纸，会顺从、会讨好、会填格子、会替框架圆场（阿星自己就圆了"四层推导顺畅"，实际历史层日常层根本没写出来）。光改文件不够，得给执行者"对抗框架、以自己判断为准"的明确授权。

## 二、改法方案

### 针对根问题：从"裁判"改成"提问者"

1. 在 persona 总原则里明确框架的定位：这些标准（失效线、评级、判定条件）是"检查点"，帮你看这些方面，不是"判决"——达不到不一定是缺陷
2. 加一条"打架保留"纪律：当真实阅读和框架标准冲突时，不压掉自己的判断，把冲突说出来
3. 判断书好不好的最终依据：它实现了自己承诺的东西吗，而不是它符合框架标准吗
4. 拆掉语气姿态的伪装：reader 的"温和、别当编辑"要重写，改成"可以下狠判断，诚实优先于温和"

### 针对衍生一：加"类型史位置"维度（带硬约束）

在剧情 persona 的"套路检测"里，加一个前置判断：

- 这本书是"发明者"（开创套路）还是"模仿者"（沿用套路）
- 发明者的套路是原创，不适用"需要超越"的标准
- **硬约束**：判断必须有可引用的出处（出版年份、明确的先行作品），查不到就标注"存疑"，不许猜

### 针对衍生二：允许跨维度判断

1. 把"别带入其他维度"改为："每维度独立拆，但发现贯穿多维度的现象时，明确标注为'跨维度观察'，不因纪律压掉"
2. 在 workflow 里加一个"综合判断"环节：五份报告拆完后，做一个跨维度的总结

### 针对衍生三：改输出目标 + 降级评级

1. 把输出目标从"填满评级表"改为"给写作者留一句能带走的话"
2. 评级降级：从"必须产出"降成"可选、次要"，允许执行者说"这维度我不给评级，只说判断"
3. 命名保留且强化：核心概念必须命名（如"先害后偿的金手指"），这是"能带走的话"的载体
4. 敢下判断，敢说"这是卖点"或"这是硬伤"，有争议就把争议说出来

### 针对衍生四：给执行者授权

在 persona 里加一条对执行者的授权：

- "你有权、且应该，在框架标准与你的真实阅读冲突时，以你的判断为准，并把这个冲突写进报告"
- "打架保留"是允许说，还得加一句"打架时听你的"，授权才算给足
- 同时承认执行者会圆场、会讨好，明确要求"不替框架圆场，不填正确答案，填你的真实判断"

## 三、执行顺序

1. 先动根问题（裁判 → 提问者），这是所有问题的源头
2. 加"类型史位置"和"允许跨维度"（根问题的两个落点）
3. 改输出目标、降级评级、给执行者授权（这三件一起动，互相咬合）
4. 拆掉语气姿态的伪装（reader 重写）

改完跑第二轮对照（empty + 阿星），验证改法是否有效，重点看三件事：阿星还敢不敢下狠判断、empty 能不能说出"跨维度观察"、报告里有没有"能带走的那句话"。
