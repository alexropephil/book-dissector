# 四维框架的方法论

## 为什么是四个维度

一部小说能被拆开看的，归根结底是四件事：

- **剧情**回答"发生了什么"，管的是骨架和节奏
- **世界观**回答"在什么规则里发生"，管的是边界和代价
- **人物**回答"谁在发生"，管的是动机和关系
- **文风**回答"用什么手感讲"，管的是语言和气息

这四件事互相独立又互相咬合。剧情靠人物的欲望推动，人物被世界的规则约束，世界靠文风营造出可信感。单独拆任何一维都看不清全貌，但四维并置，一本书的成色就摊开了。

## 拆书的底层姿势

1. **落到原文**：每个结论都要能指出原文位置，不空谈"节奏好"，要说清楚哪一章到哪一章是爽点、间隔几章。
2. **分层挖**：主角欲望分三层，主线矛盾分三层，不要停在表面的标签。
3. **给手法起名**：拆完要给每个可复用的东西命名，否则拆了就忘，带不走。

## 拆完之后

四份报告并排看，找交集：什么手法四个维度都在夸，那个就是这本书最值得学的核心。找到核心，再决定自己稿子里要不要用、怎么用。
