# 斗破苍穹（第 1-20 章）· 世界观分析

## 一、核心假设（点火点）

- **一句话核心规则**：如果一个人能否拥有力量，取决于"斗气功法等级 + 自身斗气实力 + 掌握的斗技"三者，而其中稀缺的功法、丹药、魔核都被人为垄断，那么这个世界必然长成一个"以实力排座次、以资源定生死"的等级社会。
- **点火点类型**：规则异变（斗气修炼体系成为世界唯一规则，替换了魔法/科技等一切力量形式）。
- **能推出的推论数**：至少三条可推出——① 斗气决定地位 → 废材被边缘化；② 功法等级森严 → 高阶功法被大宗门垄断 → 出身决定上限；③ 炼药师因稀缺而尊贵 → 能炼药的萧炎天然获得越级社交的钥匙。

## 二、规则层

- **规则明细**：
  - 力量阶梯：斗之气（一至十段）→ 凝聚斗之气旋成斗者 → 斗师 → 大斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗圣 → 斗帝。
  - 功法：四阶十二级（天、地、玄、黄 × 初、中、高），功法等级决定成就上限。
  - 斗技：四阶（天、地、玄、黄），是发挥斗气的特殊技能。
  - 强弱三要素：自身实力 > 功法 > 斗技（第一章末、第二章明示）。
  - 炼药师：一至九品，需"火属性 + 木属性"的变异灵魂 + 灵魂感知力。
  - 魔核：魔兽能量结晶，炼药主材料、武器/盔甲增幅材料。
- **代价**：修炼有根基风险（强行灌注会"脉断人亡"，第 9 章药老点明）；聚气散有失败率（失败则九段降回八段，第 6 章）；炼药师门槛极高（灵魂变异 + 感知力，第 6 章）。
- **例外**：焚决（黄阶低级却能进化的功法，第 9 章），是本作核心例外，也是伏笔种子；穿越带来的灵魂强度强化（第 2 章）。
- **公开性**：斗气规则人尽皆知（连坊市平民都懂魔核行情）；但焚决、薰儿身份、药老身份是秘密，构成信息差，驱动后续剧情。

## 三、力量与数值体系

- **基准原则**：有视觉化基准——斗之气用测验魔石碑的"段数"量化；斗者 = 凝聚斗之气旋（可感知的分水岭）；大斗师 = "名动一方的强者"；徽章上的金星数直接标定实力（一星到七星）。数字给作者、画面给读者，基本做到。
- **多轨制**：功法（品质）× 斗技（技能）× 实力（等级）三轨并行，阶层（大境界）与品质（功法阶位）分离清晰。
- **反膨胀机制**：功法等级硬性限制成就上限（"修炼玄阶中级功法的人，比修炼黄阶高级功法的同等级人强上几分"，第 2 章），防止战力无上限爆炸。
- **金手指自锁**：焚决设计成"黄阶低级起步、可进化"，前期不碾压、后期有成长空间，是标准自锁。
- **经济锁**：魔核"常年供不应求"、聚气散"被抄成天价"、普通斗技"顶多黄阶"，资源价格梯度堵住了低阶倒卖高阶的漏洞。
- **敌人基准**：敌人与主角共享同一套斗气体系（加列奥一星斗者、萧宁八段斗之气、葛叶七星大斗师），战斗有可推演的数值基础。

## 四、社会层

- **权力阶层**：家族（萧家/加列家/纳兰家三足鼎立）、宗门（云岚宗，加玛帝国一霸）、炼药师（凌驾于斗者之上的职业）、帝国（加玛帝国、皇室）。
- **边缘群体**：无修炼潜力的废材——成年仪式后"被分配到家族产业"或"取消进斗气阁资格"，甚至被逐出乌坦城。
- **代价承担者**：平民——萧炎月零花钱 20 金币"能让一个平民家庭饱饱过上一年"，而炼药材料动辄上千金币，贫富悬殊由规则直接制造。
- **资源竞争**：围绕魔核、丹药、功法、斗技展开；坊市被三大家族把持抽佣，魔核供不应求催生佣兵团。
- **价值观**：实力至上、等级森严。"没有实力，连一坨狗屎都不如"（第 8 章）；天才被追捧、废材被嘲讽，社会舆论赤裸地按实力站队。

## 五、历史层

- **规则时长**：斗气修炼"在无数代人的努力下发展到巅峰""扩散到民间"（第 2 章），规则存在极久。
- **关键事件**：斗气繁衍到民间、成为日常生活根基；天阶功法"已经几百年未曾出现"；萧家祖父与纳兰桀定下指腹为婚。
- **破规则尝试**：焚决的"功法进化"是规则之外的例外（第 9 章药老"没人修炼过，功法上这么介绍的"）；斗气大陆的"跳崖奇遇"文化（第 2 章）是平民对规则的妄想式挑战，结果多是断胳膊断腿。

## 六、日常层

- **普通人一天**：佣兵在魔兽山脉猎杀魔兽取魔核、在坊市摆摊交易、商人缴纳佣金、少女逛摊买手链、少年去药材店买灵药材料、去拍卖会淘换。
- **特色职业 / 焦虑 / 仪式**：炼药师（尊贵稀缺）、佣兵团（高风险赌魔核概率）、护卫队长（佩恩）；焦虑是"成年仪式"（25 岁前不成斗者不被家族认可）和"魔核概率"（半个团伤亡可能两手空空）；仪式是测验魔石碑公开测段、拜师礼、成年仪式。

## 七、类型常数配置

- **七参数**：
  - resource（资源）：魔核/丹药/功法，高度稀缺，供不应求。
  - power（力量）：斗气修炼，唯一路径。
  - threat（威胁）：家族倾轧、宗门威压、成年仪式淘汰、退婚羞辱。
  - society（社会）：阶层固化，但留了"废材逆袭"的上升通道（天赋回归）。
  - info（信息）：高度不对称（薰儿身份、药老身份、焚决秘密都是信息差）。
  - emotion（情感）：屈辱 → 雪耻的打脸爽感。
  - gravity（地理）：扩张方向放大（乌坦城 → 加玛帝国 → 斗气大陆的逐级放大感）。
- **类型归属**：玄幻（东方玄幻 / 斗气体系 + 废材逆袭）。
- **不可改边界是否守住**：守住——① 斗气是唯一力量来源（无魔法混入）；② 功法等级森严、资源稀缺；③ 升级流 + 废材逆袭的核心骨架完整；④ 金手指（药老 + 焚决）有代价有成长空间。

## 八、一致性自检

- **四层推导完整性**：规则（斗气决定强弱）→ 社会（实力排座次、废材被边缘化、炼药师尊贵）→ 历史（无数代发展、天阶功法消失）→ 日常（坊市、佣兵、药材店、拍卖会）四层可互相推导，无断裂。
- **强行设定**：少。焚决"进化"是唯一强设定，但有"没人修炼过、功法上这么写"的自我调侃处理，且作为核心伏笔。
- **设定漂移 / 降神**：前 20 章内未发现漂移或临时降神，规则前后一致。

## 九、活性检验

- **冲突（≥3 种）**：远超三种——家族内斗（长老 vs 族长）、宗门 vs 家族（退婚）、情敌竞争（加列奥、萧宁）、阶级压制（废材 vs 天才）、经济困境（缺钱买材料）、信息不对称（薰儿/药老身份）。
- **选择（困境来自规则）**：萧炎的三年之约（尊严 vs 现实）、借钱（自尊 vs 实际需求），困境都源于"实力至上"的规则本身。
- **成长路径**：药老指导 + 灵液 + 挨打训练，是"斗气规则"的自然延伸，不是硬塞的金手指。

## 专项：功能提取

- **核心功能函数**：
  - 炼药师 = f(稀缺职业) → 尊贵身份 → 主角越级社交/逆袭的合法性来源。
  - 功法等级 = f(森严的资源梯度) → 越级打脸的爽点来源。
  - 三年之约 = f(外部倒计时) → 第一阶段节奏引擎。
  - 魔核 = f(稀缺通用货币) → 经济系统与冒险动机的统一。
- **六轴提取**（以"炼药师"为例）：结构功能（给主角一条越级路径）、情感功能（尊贵身份带来的爽感）、关系功能（药老师徒关系）、角色功能（萧炎从废材到炼药师的弧线）、主题功能（实力与尊贵挂钩）、形式（火木双属性 + 灵魂感知力的职业设定）。
- **基调**：真诚直给（非反讽），幽默以"互怼"为主（药老毒舌 vs 萧炎吐槽），情感表达直接（薰儿的坦率），冲突风格偏"爆发"（退婚对峙、休书）。

## 专项：类型配置错误排查（C1-C6）

- C1 配置缺失：无。第一章测验广场即亮明"斗气"类型信号。
- C2 配置错位：无。挂玄幻标签、写的就是玄幻爽点。
- C3 配置冲突：无，纯玄幻不混类型。
- C4 噪声干扰：无，副类型（穿越）未盖过主类型（玄幻逆袭）。
- C5 必备函数缺失：无，升级、打脸、金手指、境界体系齐全。
- C6 配置模板化：有轻度倾向——戒指老爷爷、退婚、废材逆袭都是当时反复出现的元素，但本作是这些套路的早期经典形态，且"休书反杀"是有效旋转，不构成缺陷。

## 三层穿透总览

| 层级 | 核心发现 |
|------|---------|
| 底层逻辑 | 实力即一切——斗气、功法、丹药、魔核四类稀缺资源垄断，制造出"废材被踩、天才被捧"的等级世界 |
| 中层体系 | 斗气境界阶梯 + 功法/斗技双轨 + 炼药师职业 + 魔核经济，四套子系统互相咬合 |
| 表层剧情 | 废材在资源垄断的世界里，通过炼药师 + 进化功法 + 灵液，一步步夺回实力与尊严 |

## 优缺点与可复用手法

- **优点**：
  1. 世界从一条规则（斗气）长出来，四层（规则/社会/历史/日常）能互相推导，不靠名词堆砌。
  2. 经济系统真实——魔核、聚气散、功法的稀缺与价格梯度，让"缺钱"成为真实困境。
  3. 焚决"黄阶低级可进化"的自锁设计，兼顾前期不碾压与后期成长空间。
  4. 徽章（金星数）把实力可视化，读者一眼能读懂战力差。
- **缺点**：
  1. 第 2、6 章规则交代偏"教材式"直给，世界观的"展示"弱于"陈述"。
  2. 魔核概率、炼药师门槛等细节在第 11、6 章有重复解释的痕迹（设定解释略啰嗦）。
- **可复用的手法**：
  1. **一条底层规则长出一个世界**：只立"斗气决定一切"，社会、经济、日常自然推导，不自造多余名词。
  2. **实力徽章可视化**：用"金星数/段数"把抽象战力变成读者一眼能读懂的视觉符号。
  3. **稀缺资源驱动剧情**：让"魔核供不应求、灵液烧钱"直接制造主角的经济困境，推动他不断找钱、找材料。
  4. **金手指自锁（进化型）**：金手指设成"前期弱、可成长"，既不过早碾压，又留后期期待。
