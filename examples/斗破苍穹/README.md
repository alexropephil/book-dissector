# 斗破苍穹 · 拆书示例

一套完整的拆书示例：用这个项目的 persona，把一个空 agent 派去拆《斗破苍穹》前 20 章，跑出的全部成果。

## 元信息

- 拆解对象：斗破苍穹（天蚕土豆）第 1-20 章
- 使用 persona：`personas/` 下对应文件
- 执行方式：单 agent 串行（读者视角先行，四维随后，综合判断，笔记师写人读版）
- 执行者：empty（空 agent，无记忆、无专长）
- 模型：DeepSeek V4 Pro

> 这份示例特意用一个"什么都没有的空 agent"跑，就是为了证明：这套 persona 的价值是它自己的，不是靠某个有经验的 agent 撑起来的。任何人拿同样的 persona 加同样的模型，都能跑出这个水平。

## 两种报告

- **AI 阅读版**（01-06）：结构化、清单化、数据化，给 AI 提取技法、建素材库用
- **真人阅读版**（07 拆书笔记）：有立场、有温度、有节奏，给人读、偷手艺用

## 报告清单

| 文件 | 类型 | 一句话结论 |
|------|------|-----------|
| 01-剧情分析.md | AI 阅读版 | 退婚被旋转成"三年之约 + 一纸休书"的受辱立约，是废材逆袭的底层引擎 |
| 02-世界观分析.md | AI 阅读版 | 从"斗气是唯一主调"一条规则长出四层自洽系统，经济锁当剧情引擎 |
| 03-人物与情感分析.md | AI 阅读版 | 萧炎是平坦弧线，驱动力是"屈辱→打脸"情绪节奏，这是类型不是缺陷 |
| 04-文风分析.md | AI 阅读版 | 省略号节拍器 + "让得"句式 + 短句控节奏，2009 年真人作者的签名声音 |
| 05-读者体验.md | AI 阅读版 | 前六章憋、第七章爆，读者追的是"三年后他怎么赢"，不是"他会不会赢" |
| 06-综合判断.md | AI 阅读版 | 最值得学的是"屈辱量化 + 金手指给路不给果 + 爽点延迟兑现" |
| 07-拆书笔记.md | 真人阅读版 | 想写爽，先学会憋 |
