# 示例

这里放完整跑通的拆书示例。示例用一本有代表性的网文（不是古典公版书），把五份报告（四份分析 + 一份读者体验）按 `templates/` 的骨架填好。

一份真实示例比一百句介绍更有说服力。看到的人会直接明白这套框架的输出长什么样、能拆到什么颗粒度。

## 每份示例必须附元信息

- 拆解对象：书名 + 章节范围
- 使用 persona：对应 persona 文件路径
- 执行方式：单 agent 串行 / 多 agent 并行
- 模型：模型名称 + 版本

不标注模型，示例就是黑箱，别人无法判断自己的环境能不能复现同等的质量。

## 放置方式

```
examples/
└── {书名}/
    ├── README.md          # 元信息 + 拆解总览
    ├── 01-剧情分析.md
    ├── 02-世界观分析.md
    ├── 03-人物与情感分析.md
    ├── 04-文风分析.md
    ├── 05-读者体验.md
    ├── 06-综合判断.md
    └── 07-拆书笔记.md
```

注意：示例里只放分析报告，不放大段原文，更不放整本 txt。
